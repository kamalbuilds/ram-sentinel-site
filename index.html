Clean up after agent runs.

Color-coded swap readings in the menu bar tell you when pressure is rising. Headless browsers and orphaned worker trees can stay alive after a run ends. RAM Sentinel finds them and closes them in one click. Profiles you keep are never closed.

Optional autopilotOff until you turn it on. Closes leftover headless browsers on its own. Everything else waits for your click.

Pause new work while memory is critical

Use the gate in an agent loop or CI job. It exits 0 when memory is okay, 1 for a warning, and 2 when critical.

until ram-sentinel --gate; do
  sleep 30
done && claude -p "..."

A warning you can act on. A record of what worked.
